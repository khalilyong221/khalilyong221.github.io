04 ABOUT THIS PROJECT

一个自己从 0 搭到

三场景统一建模

工业、楼宇、家居不是三套系统，而是同一套点位与告警模型下的三个场景视图。

全链路闭环

接入 → 监控 → 定位 → 根因分析 → 工单，每一步都在页面上有对应落点，不只是画了几张图。

数据可回放

内置 1,000 台虚拟设备与消息流，用来验证告警阈值、拓扑联动与 AI 诊断的完整链路。
