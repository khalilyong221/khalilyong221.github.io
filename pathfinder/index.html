PathFinder Lab

寻路算法可视化实验室

BFS / DFS / Dijkstra / A*零依赖单文件随机迷宫生成逐帧回放

项目说明

一个零依赖的纯前端寻路算法可视化工具，用一张网格实时演示 BFS、DFS、Dijkstra 与 A*（曼哈顿距离启发式）四种经典算法的搜索过程：逐帧回放节点访问顺序与最终最短路径，速度可调，并给出访问节点数、路径长度、求解耗时与可达性判断。

网格支持拖动起点与终点、按住鼠标绘制墙体。随机迷宫基于随机化深度优先回溯（recursive backtracker）在奇偶网格上生长，把（奇数行、奇数列）的格子当作「房间」，在房间之间打通墙壁，因此生成的迷宫必然是一棵连通生成树，不会出现把终点堵死的情况。纯 HTML / CSS / JavaScript 实现，单文件双击即可运行。

完整案例页正在整理：算法对比、搜索过程演示与实现要点会陆续补上。
